# Personal overrides

Put optional `theme.css` or a complete `template.html` here. Both are ignored by Git and survive upstream updates. The template must retain `/*__ATLAS_DATA__*/` and consume schema version 1. Custom CSS and templates are trusted local code: review them before use. You may deliberately share sanitized themes separately.

Personal configuration and AI summaries live in `.local/`, never in this public directory. Ask AI to change these overrides instead of editing the core for ordinary personalization.
